# История изменений

## 1.0.0

Первый публичный выпуск.

**Доставка уведомлений**

- приём вебхуков Zabbix, Grafana и Alertmanager;
- durable-очередь недоставленных на диске: при недоступности TrueConf
  сообщение получает `202` и доставляется после восстановления связи;
- дедупликация и схлопывание обновлений по одному триггеру;
- защита от дублей доставки: реестр отправленного на диске не даёт повторно
  отправить сообщение после таймаута или перезапуска;
- вход через SSO: scope подбирается автоматически, недоступные исключаются
  (устранена ошибка `invalid_scope`);
- метки времени в логах приводятся к нужному поясу (`LOG_TZ`, по умолчанию
  Москва) — раньше в контейнере писались по UTC;
- перезапуск службы из панели (`SERVICE_RESTART_ENABLED`), с подтверждением;
- резервное копирование состояния: автоматические и ручные копии,
  восстановление и удаление из панели;
- редактирование чата по умолчанию прямо в панели;
- режимы реакции на восстановление инцидента (`notify`/`delete`/`resolve`/`both`)
  с переключением в панели; ключ инцидента теперь надёжно связывает
  проблему и её решение;
- режим реакции можно задать отдельно для каждого канала — он важнее
  глобального, пустое значение наследует глобальный;
- разбиение длинных сообщений, повторы и таймауты отправки.

**Отказоустойчивость**

- супервизор соединения: пересоздание `Bot` при смерти цикла SDK;
- heartbeat с режимами `off` / `smart` / `strict`;
- экспоненциальный рост паузы с переходом на «медленный» темп после
  10 минут простоя;
- «тихий» режим: при долгом простое в `error.log` остаётся одна запись.

**Управление**

- команды в чате: `/register`, `/unregister`, `/channels [стр]`,
  `/channel_edit`, `/default`, `/admins`, `/admin_add`, `/admin_remove`,
  `/token_info`;
- компактный список каналов с пагинацией и карточкой по имени;
- редактирование каналов (chat_id, название, переименование) из чата и панели.

**Веб-панель**

- компактная главная: состояние, метрики, свёрнутые подробности и логи;
- разделы: каналы, очередь, отправка, параметры, администраторы, локальный вход;
- вход через Keycloak (OIDC + PKCE) и локальный администратор;
- роли администратора и наблюдателя;
- светлая и тёмная темы;
- **диагностика**: сведения о боте и сервере, названия чатов, участники,
  присутствие бота в канале, лимиты сервера на файлы;
- **графики** динамики (отправлено, очередь, связь, перезапуски) на canvas
  без внешних библиотек;
- **календарь недели** с разбивкой уведомлений по каналам и подсказками.

**Прочее**

- раздельные логи: `bot`, `chat`, `webhook`, `error`, `delete`, `error_history`;
- корректная разметка сообщений для TrueConf (без `<code>` и «съеденных» тегов);
- `Dockerfile` и `docker-compose.yml`;
- офлайн-тесты без сети и без SDK.
